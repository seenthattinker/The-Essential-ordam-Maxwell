 # The Essential Jordan Maxwell

This project is to create a book based on the teachings of Jordan Maxwell.

## Project Structure

- **source_material/**: Directory containing downloaded audio and video content from Jordan Maxwell's lectures and presentations
- **download_source_material.py**: Automated script to download freely available Jordan Maxwell content from Internet Archive
- **DOWNLOAD_INSTRUCTIONS.md**: Comprehensive guide on how to download and organize source material

## Getting Started

### Collecting Source Material

To download Jordan Maxwell audio and video content for research:

1. **Automated Download** (Recommended):
   ```bash
   python3 download_source_material.py
   ```

2. **Manual Download**: See [DOWNLOAD_INSTRUCTIONS.md](DOWNLOAD_INSTRUCTIONS.md) for detailed instructions on alternative download methods

All downloaded files will be saved to the `source_material/` directory.

## About Jordan Maxwell

Jordan Maxwell was a researcher and speaker who specialized in:
- Occult symbolism and secret societies
- Hidden history and esoteric knowledge
- Astrotheology and ancient mysteries
- Biblical symbology and interpretation

His work spans decades of research and numerous lectures, interviews, and presentations.

## Source Material

The source material for this book comes from:
- Internet Archive collections (freely available)
- Official YouTube archive
- Odysee platform
- Public domain lectures and presentations

All content is used for educational and research purposes under fair use doctrine.

## Contributing

When adding source material:
1. Use the download script or follow the instructions in DOWNLOAD_INSTRUCTIONS.md
2. Organize files in the `source_material/` directory
3. Do not commit large media files to git (they are excluded via .gitignore)
4. Document any new sources in the source_material/README.md
